# Contributing

ORBIT is currently founder-led and is not accepting unsolicited feature pull requests. Security reports are welcome through the private process in `SECURITY.md`; non-security proposals may be discussed in an issue before implementation.

Authorized changes must use a conventional commit, preserve strict TypeScript, include the relevant safety and integration tests, and pass `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test:coverage`, and Expo prebuild checks.
