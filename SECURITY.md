# Security policy

Please do not open a public issue for a suspected vulnerability or include user data, credentials, prompts, transcripts, or exports in any report. Contact the repository owner privately through GitHub with a minimal reproduction, affected version, and impact; acknowledgement and remediation timelines will be set after triage.

Only the current `main` branch is supported during private beta. Automated dependency checks, secret scanning, branch protection, and a dedicated security mailbox should be enabled before inviting external testers.
